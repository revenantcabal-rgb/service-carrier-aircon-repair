# SpiritVale Key Helper, downloads

This repository exists so the app can check for its own updates. It holds two things and nothing
else: `version.json`, which names the newest version and its fingerprint, and the release files
under Releases.

**New here?** Open the newest release and download `SpiritVale-Key-Helper-Setup-1.7.1.exe`, then run it. Nothing else is
needed, and no Administrator password is required.

**Already have it?** Press Updates inside the app. It finds this file on its own.

The source code is not here and is not public. Nothing in this repository contains anyone's
settings, keybinds, calibration or characters.
