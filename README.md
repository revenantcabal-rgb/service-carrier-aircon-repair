# SpiritVale Helper, downloads

This repository exists so the apps can check for their own updates. It holds the version manifests
and the release files under Releases, and nothing else. The source code is not here and is not
public. Nothing in this repository contains anyone's settings, keybinds, calibration or characters.

## SpiritVale Helper 2.0.0, the current app

The new generation. It launches the game with a small in game module that reads the game's own
skill state: skills recast on their real cooldowns, buffs recast when they actually drop, and auto
attack keeps swinging while you aim with the mouse. Nothing presses anything unless you ARM it, and
one click EMERGENCY STOP always stops everything. Setup fills itself: play a little, click
Calibrate from game log, then tick your skills from a list.

**New here?** Open the newest `SpiritVale Helper` release, download `SpiritVale-Helper-2.0.0.zip`,
unzip it anywhere, open the `README.txt` inside and follow the six steps. No Administrator password
is needed.

**Already have it?** Press Updates inside the app. It finds `helper-version.json` in this
repository on its own, shows you what changed, and asks before doing anything. Your settings and
profiles are kept.

## SpiritVale Key Helper, the old app

The previous, retired generation (`version.json` and the `SpiritVale-Key-Helper` releases). It
still works and its Updates button still functions, but it is not being developed further. New
installs should use SpiritVale Helper above.
